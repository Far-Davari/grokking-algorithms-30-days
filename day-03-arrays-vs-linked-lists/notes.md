## 2. Write the Big O for these operations:

- Reading the 10th element of an array. -> `O(1)`

- Reading the 10th element of a linked list. -> `O(n)`

- Inserting at the front of an array. -> `O(n)`

- Inserting at the front of a linked list. -> `O(1)`
